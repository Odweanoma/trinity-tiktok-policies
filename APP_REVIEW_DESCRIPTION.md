# TikTok Production App Review — Submission Description

## App: Trinity TikTok Gateway

Trinity TikTok Gateway is an AI-assisted creator management tool operated through Hermes Trinity's Telegram interface.

Login Kit allows creators to securely connect their TikTok accounts. The user.info.basic and user.info.profile scopes retrieve account details, while user.info.stats provides follower and engagement statistics. The video.list scope retrieves existing videos for performance analysis and content planning.

Content Posting API supports two workflows. The video.upload scope transfers selected videos to TikTok for creators to finish posting. The video.publish scope is requested for Direct Post, allowing creators to publish existing videos after reviewing their content.

The Direct Post workflow is designed to show the connected creator, video preview, editable caption, available privacy settings and interaction controls, followed by explicit approval before publishing.

Access tokens are stored privately. Creators retain control over their content and publishing decisions.
